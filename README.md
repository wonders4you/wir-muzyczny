# Wir Muzyczny

Interaktywny ploter pola wektorowego, który gra.

Edytuj równania \(F_x(x,y)\) i \(F_y(x,y)\), oglądaj strzałki, linie przepływu
i cząstki, a pole zamienia się w dźwięk (skręt → panorama, rozbieżność → barwa,
moduł → głośność). Na telefonie: sterowanie pochyleniem.

Autor: [Tomasz Urban](https://wonders4you.com) ·
[więcej narzędzi](https://gazetkakreatywna.pl/tools/)

## Uruchomienie

```bash
npm install
npm run dev
```

Aplikacja startuje na porcie 8080.
